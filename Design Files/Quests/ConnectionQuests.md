## The Memory Box

Backstory: Anya reveals that her small wooden memory box disappeared during the Great Flood. Inside were pressed flowers, sketches, tiny notes, and little keepsakes connected to moments she shared with Ian. She has never told anyone how much she misses it because she worries they’ll think they’re “just old things.”

ID: quest_the-memory-box

Objective: Search several locations around Memorial Hill to recover Anya’s Memory Box, then return it to Anya.

Owner: Anya Thorne

Prerequisite: Anya Thorne 2 Key Event Complete

Reward: 2,500 Bellnotes

Title: The Memory Box

Type: Connection Quest
