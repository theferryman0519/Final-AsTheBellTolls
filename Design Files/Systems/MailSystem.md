## Base Information

- Mail is received at the Manor's mailbox at the start of each day, if mail is received.
- Mail can hold just text or both text and gifted items.

---

## Mail Types

- Humor notes
- Event reminders
- Quest requests
- Event requests
- Overflow item rewards
