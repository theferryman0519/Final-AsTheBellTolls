# Information

This table defines NPC-to-NPC interactions that are strong enough to influence routine authoring and potentially create an NPC Interaction Override in the NPC Routine System.

The table is not a copy of every Friend or Acquaintance entry in the character profiles. It prioritizes relationships supported by family/household ties, Best Friend relationships, mentorships, rivalries, crushes, shared workplaces, and recurring interactions already described in character schedules.

## Interaction Status

- Established: Directly supported by the uploaded character profiles and/or existing routine text.
- Recommended: Supported by the characters' established relationship and characterization, but the exact recurring interaction is not yet explicitly scheduled in the source profiles.
- Directional: The relationship label is stronger from one character's perspective than the other's. This is preserved rather than automatically reconciled.

## Frequency

- Daily: Expected most days unless another override supersedes it.
- Several Times Weekly: Usually 2-4 times per week.
- Weekly: Usually one planned interaction per week.
- Biweekly / Monthly: Lower-frequency relationship time.
- Occasional: No fixed cadence required.
- Event / Progression: Used when story or relationship progression makes the interaction appropriate.

# Authoring Rules for NPC Interaction Overrides

- Do not create an NPC Interaction Override simply because two NPCs are listed as Friends.
- Prefer established family, household, Best Friend, mentor, rival, crush, or recurring schedule relationships.
- If all participating NPCs already have the same Location and compatible Activity in their Base Routine, the interaction can remain part of Base Routine rather than creating a redundant override.
- Use NPC Interaction Override when the social connection changes one or more participants' normal Location or Activity for that tick.
- All participants in a scheduled interaction should resolve to the same interaction, compatible Location, and compatible time window.
- Directional relationship labels are preserved. A character can view another as a Best Friend, Mentor, Friend, or Crush without requiring the other character to use the same label.
- Household membership can produce routine interaction even when the profile relationship label is only Acquaintance, because co-residence creates natural shared-space opportunities. This should not automatically upgrade the relationship label.
- Work-based relationships should use Activities such as Working, Repairing, Teaching, or Attending rather than forcing all NPC interactions into Socializing.
- Lower-frequency relationships are preferable to overscheduling the cast. Every meaningful connection does not need a weekly appointment.
