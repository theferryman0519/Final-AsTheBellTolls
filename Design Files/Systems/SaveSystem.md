## Information

- Players will have their games saved automatically at the end of each day.
- There will be no manual saving during the course of a day.
- Players will be able to have multiple save files.

---

## Save Data

- Player Save Data
- Individual NPC Save Data
- Manor Restoration Progress Save Data
- Blackmere Restoration Progress Save Data
- Settings Save Data
- Achievements Save Data
- Quest States Save Data
