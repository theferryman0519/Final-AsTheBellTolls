## Information

- Gameplay Systems operate independently where possible but communicate when one system affects another.
- Each System remains responsible for its own gameplay data and behavior.
- Systems should not duplicate ownership of the same gameplay data.
- When multiple Systems affect the same gameplay action, the appropriate System Interaction Rule determines how those Systems interact.
- System interactions should occur through defined events, requests, or shared gameplay data rather than unnecessary direct dependencies.

## Priority Rules

- Game Events override normal NPC Routines when an NPC is participating in the event.
- Festival Routines override normal NPC Routines for participating NPCs.
- Quest-specific NPC behavior overrides normal NPC Routines when required.
- Dialogue prevents the participating NPC from continuing normal navigation.
- Gameplay Menus and the Player Menu pause normal game time.
- Day End prevents new normal gameplay interactions from beginning.
- Scene transitions temporarily prevent normal player interactions.
- Modal UI prevents interaction with UI underneath the modal until it is closed.

---

## Day End Processing

When the current day ends:

1. Normal Gameplay ends.
2. End-of-day gameplay data is processed.
3. Relationship changes are displayed.
4. Timing Progress is displayed.
5. End of Day Selling is processed and displayed.
6. Tomorrow's Events are displayed.
7. The Calendar advances to the next day.
8. Daily gameplay limits and states are reset as necessary.
9. The next day's Weather becomes active.
10. NPCs receive the appropriate routine for the new day.
11. The game is saved.
12. The next day begins.

## System Ownership

- Time System owns the current game time.
- Calendar System owns the current date.
- Weather System owns the current Weather.
- Inventory System owns the player's stored Items.
- Economy System owns the player's Bellnotes.
- Stamina System owns the player's current Stamina.
- NPC Friendship System owns Friendship progression.
- NPC Connection System owns Connection progression.
- Quest System owns Quest progression.
- Game Event System owns Game Event states and completion.
- NPC Routine System owns the currently selected routine for each NPC.
- NPC Navigation System owns physical NPC navigation.
- Game State System owns the current high-level Game State.
