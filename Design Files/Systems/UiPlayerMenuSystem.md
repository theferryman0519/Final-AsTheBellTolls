## Information

- The Player Menu is accessed by pausing the game.
- Opening the Player Menu pauses game time and disables normal Gameplay input.
- The Player Menu contains twelve selectable pages.
- Selecting a page opens that page while keeping the Player Menu active.
- Returning from a page returns the player to the Player Menu.
- Closing the Player Menu returns the player to Gameplay.

---

## Player Menu Pages

| Player Menu Page | Information                                                        |
|------------------|--------------------------------------------------------------------|
| Player           | Displays player information, current buffs, and other player data. |
| Inventory        | Displays the player's Tool Belt and Satchel.                       |
| Relationships    | Displays NPC Friendship and relationship information.              |
| Manor            | Displays restoration progress of the manor rooms.                  |
| Town             | Displays restoration progress throughout Blackmere.                |
| Quests           | Displays Active and Completed Quests.                              |
| Inventions       | Displays Completed, Available, and Unavailable inventions.         |
| Calendar         | Displays the current seasonal Calendar and upcoming events.        |
| Map              | Displays the map and available location information.               |
| Ledger           | Displays collection and completion progress.                       |
| Settings         | Displays game settings and accessibility options.                  |
| Quit Game        | Provides options for leaving the current game session.             |

---

## Navigation

- Selecting a page transitions from the Player Menu to the selected page.
- Back or Cancel from a page returns to the Player Menu.
- Back or Cancel from the Player Menu closes it.
- The Player Menu supports Keyboard & Mouse and Controller navigation.
- Player Menu pages may display information from other gameplay systems but do not directly advance game time.
